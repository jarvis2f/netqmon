# Security Policy

## Supported Versions

We provide security updates for the following versions of NetQmon:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

The NetQmon team takes security issues seriously. If you discover a security vulnerability in NetQmon, please report it responsibly rather than opening a public issue.

### Preferred Method: GitHub Private Vulnerability Reporting

Please report security issues privately through [GitHub Security Advisories](https://github.com/jarvis2f/netqmon/security/advisories/new).

### What to Include in Your Report

To help us triage and resolve the issue quickly, please provide:
* A clear description of the vulnerability and its potential impact.
* Step-by-step reproduction instructions or a minimal proof-of-concept.
* The affected component(s) (`netqmon-agent`, `netqmon-collector`, `controller-ui`, or packaging).
* Operating environment details (OS, OpenWrt architecture/version, kernel version, Docker version).
* Any suggested mitigations or patches, if available.

### Response Process

* We will acknowledge receipt of your vulnerability report within 48 hours.
* We will confirm the issue, assess the severity, and work on a fix in a private advisory.
* Once a fix is verified and released, we will publish a public advisory acknowledging your contribution (unless you prefer to remain anonymous).
