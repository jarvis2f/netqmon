# NetQmon v1.1.1-beta.1

本次预发布主要改善 Controller 页面响应速度，并修复 DPI 采样解析异常。

## 改进与修复

- 首页、客户端列表和详情页改用轻量实时摘要，以连接计数替代全量连接明细；首页趋势历史在首次连接时加载，后续只推送最新数据点。
- 首页各区域独立加载，慢请求或局部接口失败不会阻塞其他区域显示。
- 历史查询使用有并发上限的阻塞任务，减少慢查询对请求处理线程的影响。洞察结果缓存 10 秒，并合并相同请求的并发计算。
- 优化 SQLite 查询条件与目的地址去重索引，总流量图表和汇总复用同一次数据扫描。索引仅包含稳定字段，避免为持续更新的流量计数器增加索引写入。
- 修复 TLS ClientHello 握手长度检查不足导致的切片越界，避免畸形或不完整采样终止 DPI 工作线程。
- OpenWrt 发布新增变更检测，仅在 Agent、共享协议、eBPF、相关依赖或构建打包输入变化时执行构建和发布；忽略 Controller、文档和单纯版本号变化，保留手动强制构建。

## 升级说明

- 本版本继续支持 SQLite 和 ClickHouse，不会自动切换存储后端。
- SQLite 启动时自动执行第 10 号迁移，重建目的地址查询索引；现有流量记录保留，首次启动耗时和额外磁盘占用取决于保留的数据量。
- OpenWrt 变更检测分别比较 stable 和 beta 通道。本次包含工作流和检测脚本的更新，因此会执行一次相关构建。
- Controller 镜像由标签工作流构建并发布为 `ghcr.io/jarvis2f/netqmon:v1.1.1-beta.1`；预发布不更新稳定版的 `latest` 标签。镜像和 OpenWrt 附件的可用状态以对应工作流结果为准。

## 验证范围

- Controller 后端与存储回归测试通过；后端测试使用纯 Rust 模式，未执行原生 nDPI 引擎联调。
- 19 项浏览器回归、前端构建、类型检查及相关 ESLint 检查通过。
- 20 项发布相关测试通过，覆盖版本号变化、依赖变化、stable/beta 通道、手动触发与 Agent 文件重命名。
- 性能改进已使用合成数据验证，未部署到生产环境测量实际提升。
